# Data

This folder contains the input and output files used in the FES-MADM II Version 1.1.0 LPI case study.

The data support the manuscript:

**“FES-MADM II: A Fuzzy Entropy–Synergy Multi-Attribute Decision Framework for Information-Aware Assessment of National Logistics Performance.”**

## Folder structure

```text
data/

├── input/
│   ├── FESMADM2_CaseStudy_LPI_a0_INPUT.xlsx
│   ├── FESMADM2_CaseStudy_LPI_a0_5_INPUT.xlsx
│   └── FESMADM2_CaseStudy_LPI_a1_INPUT.xlsx
│
└── output/
    ├── FESMADM2_CaseStudy_LPI_a0_v1_1_0.xlsx
    ├── FESMADM2_CaseStudy_LPI_a0_5_v1_1_0.xlsx
    └── FESMADM2_CaseStudy_LPI_a1_v1_1_0.xlsx
```

## Input files

The `input/` folder contains the case-study input files used by the R/Shiny implementation. These files include the central LPI performance matrix, fuzzy deviation matrix, subjective weight inputs, criteria orientation and α-cut configuration.

The three input files correspond to the α-cut scenarios analysed in the manuscript:

```text
α = 0
α = 0.5
α = 1
```

## Output files

The `output/` folder contains the structured Excel outputs generated by the FES-MADM II R/Shiny implementation for each α-cut scenario.

The output files include, where applicable:

* alternative scores and rankings;
* subjective, objective and integrated criteria weights;
* Integrated Criteria Importance values;
* entropy measures;
* entropy-based diagnostic indices;
* structured results suitable for verification and reporting.

## Reproducibility note

The Excel files in the `output/` folder are generated outputs from the R implementation. They are provided for transparency, verification and manuscript replication. The computational logic is implemented in R and not through Excel formulas.
