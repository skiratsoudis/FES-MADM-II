# Changelog

## Version 1.1.0

Version 1.1.0 updates the FES-MADM II reproducibility package for the revised manuscript submitted to *Operational Research*.

### Changes

* Corrected the α-cut operationalisation of triangular fuzzy numbers, aligned with the standard interpretation where α = 0 corresponds to the full support and α = 1 collapses to the central value.
* Updated the R/Shiny implementation of the FES-MADM II model.
* Updated the LPI case-study output files for α = 0, α = 0.5 and α = 1.
* Added a standalone R script with embedded data for reproducing all manuscript figures except the conceptual workflow diagram.
* Added a standalone fuzzy TOPSIS benchmark script with embedded data.
* Added a static fuzzy TOPSIS benchmark output file containing closeness coefficients, rankings, rank differences and concordance indicators.
* Improved computational and graphical reproducibility documentation.

## Version 1.0.0

Initial public release of the FES-MADM II R/Shiny implementation and LPI case-study reproducibility package.
